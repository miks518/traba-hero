# AGENTS.md

## Project Overview

Trabahero is a job-scam detection browser extension for Filipino job seekers. It uses local AI (LM Studio) to analyze job postings for fraud signals without cloud APIs.

**Two-tier architecture:**
- **Extension** (root): React 19 + TypeScript + Tailwind, built with WXT framework
- **Backend** (`backend/`): FastAPI Python proxy, no AI logic — calls LM Studio

## Quick Commands

```bash
# Extension (from project root)
npm run dev              # Dev server (auto-reload)
npm run build            # Build for Chrome
npm run compile          # TypeScript check (no emit)
npm run zip              # Package for distribution

# Backend (from backend/)
python -m uvicorn app.main:app --reload --port 8000

# Backend setup (first time)
cd backend
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
Copy-Item .env.example .env
```

**Start order:** LM Studio → backend → extension

## Key Architecture

- `entrypoints/background.ts` — Opens sidepanel on toolbar click
- `entrypoints/content.tsx` — Element picker overlay for screenshot capture
- `entrypoints/sidepanel/` — Main React app (views, components, types)
- `entrypoints/sidepanel/lib/api.ts` — HTTP client → `localhost:8000`
- `entrypoints/sidepanel/views/` — ScamScanView, ResumeMatchView
- `backend/app/routers/scan.py` — All API endpoints (/api/scan, /api/scan-text, /api/analyze-resume, /api/match-resume)
- `backend/app/services/lm_client.py` — LM Studio OpenAI-compatible client
- `backend/app/config.py` — Settings via pydantic-settings, loads from `backend/.env`

## Conventions

- **WXT globals**: `defineBackground()`, `defineContentScript()` are auto-imported by WXT — do NOT import them
- **Chrome APIs**: Use `// @ts-ignore` for `chrome.sidePanel`, `chrome.storage` in extension context
- **Tailwind theming**: Colors use CSS variables (`var(--color-*)`) defined in theme JSON files under `design/`. Use semantic tokens like `bg-background`, `text-on-surface`, not raw hex
- **Custom fonts**: `font-headline` (Hanken Grotesk), `font-body`/`font-label` (Inter)
- **Tactile shadows**: Use `shadow-tactile`, `shadow-card` for 3D button/card effects
- **TypeScript**: `tsconfig.json` extends `.wxt/tsconfig.json` (auto-generated by `wxt prepare`)

## Gotchas

- `wxt prepare` runs on `postinstall` — generates `.wxt/` directory with tsconfig and types
- `.wxt/` and `.output/` are gitignored — never commit them
- Backend reads `SYSTEM_PROMPT.md` from project root (not backend dir) — path resolved via `Path(__file__).resolve().parents[3]`
- Extension API client (`lib/api.ts`) hardcodes `http://localhost:8000` — must match backend port
- No lint/format/test commands configured — only `npm run compile` for type checking
- No CI workflows exist
- Dark mode is toggled via `document.documentElement.classList.toggle('dark')` — Tailwind uses `darkMode: 'class'`
